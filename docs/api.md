# HTTP API

Сервис отдаёт лендинг, приложение и JSON API с одного порта. Ответы `/api/*` не кэшируются (`Cache-Control: no-store`), тело запроса ограничено 16 КиБ. Ошибки приходят как `{"error": "<сообщение>", "code": "<код>"}`.

Авторизация: заголовок `Authorization: Bearer <токен сессии>`. Токен выдают `POST /api/auth/telegram` (Telegram, 12 часов) и `POST /api/auth/guest` (гость, 30 дней).

| Маршрут | Назначение |
|---|---|
| `GET /` | Лендинг. |
| `GET /privacy` | Страница о конфиденциальности: куки, хранилище браузера, данные. |
| `GET /app` | Приложение (одностраничное, тот же адрес открывает Telegram Mini App). |
| `GET /api/pairs` | Режимы и 40 готовых пар. |
| `GET /api/config` | Что странице нужно до входа: `guests` (включён ли гостевой вход) и `turnstileSiteKey`. |
| `POST /api/auth/telegram` | Вход из Mini App: `{"initData": "..."}` → токен сессии. 30 запросов в минуту с IP. |
| `POST /api/auth/guest` | Вход гостем: `{"challenge": "<ответ Turnstile>"}` → токен сессии. 10 запросов в минуту с IP. |
| `GET /api/me` | Сессия: `id`, `guest`, квота на сегодня (`quota`), доступен ли AI (`aiEnabled`). 120 запросов в минуту с IP. |
| `POST /api/translate` | `{text, mode, level, previous?}` → `{resultId, text, source: "pair"\|"ai", quota}`. `previous` просит другой вариант. 30 запросов в минуту с IP. |
| `POST /api/events` | Клиентские события метрики `{events:[{type, kind, mode, level, resultId}]}`: до 10 за запрос, без текста. Ответ 204; сессия необязательна. 60 запросов в минуту с IP. |
| `POST /bot/webhook` | Вебхук бота (только при заданном `WEBHOOK_SECRET`). Без верного секрета в заголовке `X-Telegram-Bot-Api-Secret-Token` отвечает 403. |
| `GET /healthz` | Живость: не зависит от базы. |
| `GET /readyz` | Готовность: проверяет базу. Ответ кэшируется на 2 секунды. |

Метрики Prometheus отдаёт отдельный порт `METRICS_ADDR`, а не публичный: см. [операции](./operations.md#метрики).

## Коды ошибок

| Код | Статус | Когда |
|---|---|---|
| `invalid` | 400 | Некорректный запрос: пустой или слишком длинный текст (до 6000 символов), неизвестный режим, уровень не 1–3. |
| `quota_exhausted` | 429 | Дневная квота исчерпана. Ответ несёт `quota` с `resetsAt`. |
| `rate_limited` | 429 | Лимит запросов с IP. |
| `challenge_failed` | 403 | Гость не прошёл проверку Turnstile. |
| `guests_disabled` | 404 / 503 | Гостевой вход выключен конфигурацией (404) или остановлен администратором (503). |
| `budget_exhausted` | 503 | Исчерпан суточный потолок расходов (для гостей: их доля). Квота не потрачена. |
| `free_stopped` | 503 | Администратор остановил AI-переводы. Готовые пары работают. |
| `ai_disabled` | 503 | Не задан `AI_API_KEY`. Готовые пары работают. |
| `unavailable` | 502 | Провайдер AI не ответил. Квота не потрачена. |

Сессия недействительна или отсутствует: 401; пользователь заблокирован: 403.
