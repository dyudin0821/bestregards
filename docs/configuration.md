# Конфигурация

Сервис настраивается только переменными окружения; образец со всеми значениями: [.env.example](../.env.example). Ошибки в настройках сервис показывает все сразу при старте и не запускается.

## Обязательные

| Переменная | Назначение |
|---|---|
| `DATABASE_URL` | Строка подключения к PostgreSQL. Вне локальной машины нужен `sslmode=require`. |
| `BOT_TOKEN` | Токен бота (BotFather): по нему проверяется подпись Mini App и вызывается Bot API. Без пробелов и переводов строки. |
| `SESSION_SECRET` | Не короче 32 символов. Подпись токенов сессии. |
| `EVENTS_PEPPER` | Не короче 32 символов. Ключ хэша пользователя в событиях: секретный и неизменный (после смены прежние события нельзя связать с пользователями). |

## Необязательные

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `PORT` | `8080` | Порт сервиса (1–65535). |
| `DB_MAX_CONNS` | `10` | Соединений с базой на процесс, не меньше 3 (миграции держат два). Реплики × это число должно быть меньше `max_connections` базы. |
| `TRUST_PROXY` | `0` | `1` только за одним доверенным прокси: адрес клиента берётся из последней записи `X-Forwarded-For`. |
| `QUOTA_TZ` | `Europe/Moscow` | Часовой пояс, в котором начинаются сутки квоты и потолка. |
| `EVENTS_RETENTION_DAYS` | `365` | Сколько хранятся события; чистит `bestregards purge`. |
| `METRICS_ADDR` | пусто | Адрес отдельного порта метрик, например `:9090`. Пусто: метрики выключены. |
| `METRICS_TOKEN` | | Не короче 16 символов. Bearer-токен для `/metrics`. |
| `OTEL_EXPORTER_OTLP_ENDPOINT` | | Включает трассировку; остальные `OTEL_*` читает SDK. См. [операции](./operations.md#трассировка). |

### Гости сайта

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `TURNSTILE_SECRET`, `TURNSTILE_SITE_KEY` | | Cloudflare Turnstile; задаются **только вместе**. Включают гостевой вход на сайте. |
| `GUESTS_WITHOUT_CHALLENGE` | `0` | `1` пускает гостей без проверки. **Только для локальной разработки:** в продакшене скрипты смогут плодить гостей без ограничений. |

Если не задано ничего из этого, гости выключены, и сайт работает только внутри Telegram.

### Бот

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `WEBHOOK_SECRET` | | 32–256 символов `A-Za-z0-9_-`. Включает вебхук бота (кнопка `/start`, панель `/admin`); тогда обязателен `PUBLIC_URL`. |
| `PUBLIC_URL` | | https-адрес сервиса без пути. Из него строятся вебхук (`/bot/webhook`) и кнопка Mini App (`/app`). |
| `ADMIN_IDS` | | Telegram-id администраторов через запятую: им доступен `/admin`, и у них нет суточной квоты AI-переводов (потолок расходов действует). Пусто: `/admin` никому не доступен. |

### AI

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `AI_API_KEY` | | Ключ провайдера. Без него работают только готовые пары. |
| `AI_BASE_URL` | `https://openrouter.ai/api/v1` | OpenAI-совместимый API. Только https (http допустим для `localhost`). |
| `AI_MODEL` | `deepseek/deepseek-v4-flash` | Модель. |
| `AI_PRICE_INPUT_USD_PER_MTOK`, `AI_PRICE_OUTPUT_USD_PER_MTOK` | | Цены провайдера в долларах за миллион токенов. Обязательны с `AI_API_KEY`: по ним считается потолок расходов. |
| `FREE_BUDGET_USD_PER_DAY` | `10` | Суточный потолок расходов на AI. Устройство: [квоты и расходы](./quotas-and-spending.md). |

### Только для локальной разработки

`POSTGRES_PASSWORD`: пароль базы из `compose.yaml`; сервису не нужен, но тот же пароль идёт в `DATABASE_URL`.

## Секреты должны быть разными

`BOT_TOKEN`, `SESSION_SECRET`, `EVENTS_PEPPER`, `WEBHOOK_SECRET`, `METRICS_TOKEN` и `TURNSTILE_SECRET` не должны совпадать между собой: иначе утечка одного стала бы утечкой другого. Сервис проверяет это при старте.

## AI-провайдер

Подойдёт любой OpenAI-совместимый API (`/chat/completions`). Рекомендуется **OpenRouter с дешёвой платной моделью класса DeepSeek**:

```sh
AI_BASE_URL=https://openrouter.ai/api/v1
AI_MODEL=deepseek/deepseek-v4-flash
AI_PRICE_INPUT_USD_PER_MTOK=0.09
AI_PRICE_OUTPUT_USD_PER_MTOK=0.18
```

Цены сняты со списка моделей OpenRouter 22.11.2026. Перед запуском сверьте их и модель с актуальными и пересчитайте `FREE_BUDGET_USD_PER_DAY`.

**Почему не модель с суффиксом `:free`.** OpenRouter ограничивает бесплатные модели 20 запросами в минуту и 1000 в сутки на аккаунт (50 в сутки, пока куплено меньше $10 кредитов). Лимит общий для всех пользователей, и новые ключи его не увеличивают, так что вирусный всплеск положил бы сервис. К тому же бесплатные эндпоинты могут логировать промпты. Платная дешёвая модель стоит копейки и ограничена только потолком расходов.

Для другого провайдера задайте `AI_BASE_URL`, `AI_MODEL` и цены. Для моделей семейства `gpt-6-luna` запрос строится с параметрами нового поколения (`reasoning_effort`, `max_completion_tokens`); для остальных используются `temperature` и `max_tokens`.
