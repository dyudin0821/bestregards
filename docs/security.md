# Безопасность и данные

Об уязвимости сообщайте мейнтейнеру приватно, а не в публичном issue.

## Что стоит знать при эксплуатации

- **Вход.** `initData` Telegram принимается в течение часа, сессия пользователя живёт 12 часов, сессия гостя 30 дней. Токены подписываются HMAC с доменным префиксом. Секреты `BOT_TOKEN`, `SESSION_SECRET`, `EVENTS_PEPPER`, `WEBHOOK_SECRET`, `METRICS_TOKEN`, `TURNSTILE_SECRET` не должны совпадать (сервис не запустится).
- **Гости.** Гостя может завести любой, кто прошёл Turnstile (решатели капчи стоят порядка $1–3 за тысячу), поэтому защита от истощения расходов многослойная: лимит 10 гостей в минуту с IP, доля гостей 40% от почасового лимита (пользователи Telegram не страдают), кнопка «Остановить гостей» в `/admin` и суточный потолок. Что остаётся: скрипт может выбрать долю гостей, и тогда гости на сайте получат `budget_exhausted` до следующего часа. Гость, очистивший данные браузера, получает новую квоту: это принято. Утечка `TURNSTILE_SECRET` не катастрофична (секрет позволяет лишь проверять ответы, а не выдавать их), но он должен быть отдельным. `GUESTS_WITHOUT_CHALLENGE=1` убирает единственную защиту от скриптов: не включайте в продакшене.
- **События.** `POST /api/events` не требует входа: до 10 событий за запрос, один `translate_done` и один `copied` на результат (уникальные индексы), лимит по IP. События готовых пар клиент присылает сам и может подделать: это принято. AI-переводы и отказы по квоте пишет только сервер.
- **Расходы на AI.** Деньги резервируются до вызова провайдера и сверяются с фактом: [квоты и расходы](./quotas-and-spending.md). Предыдущий вариант (`previous`) уходит модели пользовательской репликой в разделителях, а не репликой ассистента.
- **Лимиты по IP.** IPv6 считается по блоку /64; таблица ограничена по размеру (при переполнении новый ключ вытесняет самый давний из небольшой выборки); при `TRUST_PROXY=1` берётся только последняя запись последней строки `X-Forwarded-For`, и только если это IP-адрес. `/api/me` и `/api/auth/*` ограничены по IP. `/readyz` отвечает из кэша на 2 секунды, поэтому поток проб не нагружает базу.
- **Заголовки.** CSP без `unsafe-inline` для стилей, с `form-action 'none'`; `https://challenges.cloudflare.com` разрешён в `script-src` и `frame-src` (Turnstile), `https://telegram.org` в `script-src`; HSTS, Permissions-Policy.
- **Бот.** Каждое нажатие в `/admin` заново проверяет `ADMIN_IDS`; действия администраторов пишутся в лог (`audit=true`). Вебхук без верного `X-Telegram-Bot-Api-Secret-Token` получает 403.
- **Метрики** слушают отдельный порт: задайте `METRICS_TOKEN` или закройте порт сетевой политикой.
- **Исходящий URL** (`AI_BASE_URL`) должен быть https; http допускается только для localhost.
- **Образы** закреплены по дайджесту; обновляет их Renovate ([CI](./ci.md#обновление-зависимостей)).
- **Не публикуйте** `.env`, токены и ключи.

## Какие данные хранятся

В базе только:
- идентификатор Telegram (у гостя сайта отрицательный номер без привязки к человеку);
- метка первого запуска (`start_param`), признак блокировки, время визитов;
- счётчик использованной квоты по дням и суммарные расходы по дням;
- переключатели аварийного стопа;
- псевдонимизированные события использования: ключёвой хэш вместо идентификатора, кампания, режим, уровень. По GDPR это всё ещё персональные данные (хэш с секретным ключом оператор может воспроизвести). Хранятся `EVENTS_RETENTION_DAYS` дней (по умолчанию 365).

Строки гостей удаляются через 44 дня. Строки пользователей Telegram автоматически не удаляются (только по запросу): это пробел перед запуском, нужен срок хранения для неактивных записей. Имена, юзернеймы, IP-адреса и тексты не сохраняются. Определения метрик: [metrics.md](./metrics.md).

Куда данные уходят:
- Оригинал текста уходит провайдеру AI только при переводе своего текста. Модерации нет: мат разрешён, продукт сатирический.
- Для проверки Turnstile IP гостя передаётся Cloudflare.
- История переводов (до 30 записей) лежит в `localStorage` браузера, но только с согласия посетителя. Токен сессии Telegram-пользователя хранится только в памяти страницы, токен гостя живёт 30 дней в браузере.

Логи содержат Telegram-идентификаторы администраторов (аудит), но не тексты: [операции](./operations.md#логи).

## Куки и хранилище браузера

**Куки сервис не ставит.** В браузере используется `localStorage` и `sessionStorage`; страница для посетителей: `/privacy` (исходник [web/privacy.html](../web/privacy.html)).

| Данные | Категория | Без согласия |
|---|---|---|
| Гостевой вход `bestregards.guest.v1` | необходимое | да |
| Выбор посетителя `bestregards.consent.v1` | необходимое | да |
| Проверка Turnstile, `__telegram__*` (пишут чужие скрипты) | необходимое | да |
| История переводов `bestregards.history.v1`, тема `bestregards.theme` | необязательное | **нет** |

Окно выбора даёт [vanilla-cookieconsent](https://cookieconsent.orestbida.com/) с `useLocalStorage: true`, чтобы сам выбор не был кукой. Без согласия история и тема не читаются и не пишутся, а отказ удаляет уже сохранённое. Настройки окна: [consent.js](../web/src/consent.js), правила чтения и записи: [storage.js](../web/src/storage.js).

При изменении того, что хранится в браузере, обновите три места: `/privacy`, тексты в `consent.js` и `CONSENT_REVISION` в `storage.js` (после этого все посетители увидят окно заново). Скрипт Telegram загружается только при запуске из Telegram ([sdk.js](../web/src/sdk.js)): посетитель обычного сайта к telegram.org не обращается.

## Правовая рамка

Решение и альтернативы: [ADR 0006](./adr/0006-legal-frame-gdpr.md), [ADR 0007](./adr/0007-consent-without-cookies.md).

Оператор: физическое лицо, резидент ЕС; сервер и база в Финляндии. Политика на `/privacy` написана под GDPR (ст. 13) и под правила ЕС и Финляндии о хранении данных в браузере (Директива 2002/58/EC ст. 5(3), финский закон 917/2014 §205, Руководство EDPB 2/2023). Сервис заявлен как **не адресованный гражданам РФ**, поэтому 152-ФЗ в политике не применяется.

Что осталось незакрытым перед публичным запуском:
- Текст не проверен юристом.
- Для Telegram-пользователей нет срока хранения неактивных записей и автоматического удаления: удаление идёт по письму.
- Нужно проверить договорные основания передачи данных в США (AI-провайдер, Cloudflare) и вести реестр обработки (ст. 30 GDPR).
- Нет страницы «Условия»: ссылка в футере лендинга пока пустая.
- Заявление «не для граждан РФ» противоречит русскоязычному сайту и рекламе на русском: оно не гарантирует, что российский закон не будет применён.
